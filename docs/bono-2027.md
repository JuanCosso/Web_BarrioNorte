# Gestión del Bono 2027

Los grupos se administran desde **Panel de Administración → Bono 2027**. Al marcar un grupo como vendido o disponible, el estado se guarda en PostgreSQL y se actualiza en la página pública sin un nuevo deploy.

## Activación inicial

Aplicar el modelo nuevo al PostgreSQL configurado en `DATABASE_URL` una sola vez:

```bash
npx prisma db push
```

Los grupos iniciales se crean automáticamente al consultar la página del bono o abrir la pestaña de administración. Los estados existentes no se sobrescriben.
